# 変更履歴

ルールの変更を、新しい順に書く。取り込んだ側は、前回の取り込み以降の項目を読み、
「使っている側で直すこと」に従って手元の CSS や設計書を直す。

## 2026-11-15

**変更**

- 流れの先頭の余白の打ち消しを、`:where()` に入れずに `> :first-child`（[0,2,0]）で書くことにした（1・4・7 節）。
  詳細度で `__要素` の余白に勝つので、block の定義の最後に置かなくてよくなり、
  block の定義の中にまとめて書ける。これまでは `> :where(:first-child)` を最後に書き、記述順で勝たせていた
- 「書き終えたら確認すること」と、ひな形の `stylelint.config.mjs` のコメントを合わせた

**使っている側で直すこと**

- `> :where(:first-child)` で書いた先頭の打ち消しを、`> :first-child` に書き換える。
  書き換えたら、block の定義の中に移してよい
- 状態を重ねて [0,2,0] にしたセレクタ（`.c-a__b:hover` など）で `margin-block-start` を変えていたら、
  打ち消しに勝ってしまうことがあるので、見直す

## 2026-11-14（2）

**変更**

- 素の要素は外側の余白を持たない、と明記した（2・4・7 節）。
  ブラウザが既定で付ける `margin` は `reset` で 0 にし、`base` でも付けない。
  文脈の余白は `__要素` クラスで、クラスのない HTML には `.c-prose` で与える。
  これまでは 4 節の冒頭の前提が、既定の余白を残す読み方も許していた
- 「書き終えたら確認すること」と、ひな形の `global.css` のコメントに同じことを足した

**使っている側で直すこと**

- `reset` で、見出し・段落・リストなどの `margin` を 0 にする。`dialog` などの位置合わせの `auto` は残す
- `base` で素の要素に `margin` を付けていたら、消す
- 素の要素の余白に頼っていた場所は、`__要素` クラスで文脈の余白を与えるか、クラスのない HTML なら `.c-prose` で包む
- 余白が変わるので、ページごとに見た目を確かめる

## 2026-11-14

**変更**

- ひな形の `stylelint.config.mjs` を Stylelint 18（`stylelint-config-standard` 41）に合わせた。
  18 で `selector-max-specificity` の `ignoreSelectors` がなくなったため、詳細度の上限を
  `"0,2,0"` に戻した。状態を重ねた [0,2,0] と組み合わせの [0,2,0] は検査では区別できないので、
  書く側が守る（1 節に書いた）

**使っている側で直すこと**

- `stylelint` を 18 以上に、`stylelint-config-standard` を 41 以上に上げる。Node.js は 22.22.2 / 24.15.0 以上が要る
- `stylelint.config.mjs` の `selector-max-specificity` を、ひな形と同じ `"0,2,0"` に差し替える
- そのほかの 18 での変更は、Stylelint の移行ガイド（`docs/migration-guide/to-18.md`）で確かめる

## 2026-11-02

**変更**

- 4 節に「はみ出し（負の margin）」の小節を足した。
  親の `padding` の分だけ外へはみ出させる書き方を、余白とは別の手法として扱う
- 「8. 状態と動き」の節を足した。状態は属性（`aria-*`、`data-*`）で表し、
  JS が動いて初めて元に戻る見た目は `scripting` で囲み、装飾のための大きな動きは
  `prefers-reduced-motion: no-preference` の中にだけ書く。
  7 節の hover の項目は 8 節へ移した。旧 8・9 節は 9・10 節になった
- 1 節で、[0,2,0] まで許す「状態」を、その要素自身の状態に限ると明記した。
  ほかの要素の状態や文脈、構造の疑似クラスは `:where()` に入れる。疑似要素で増える分は数えない
- ひな形の `stylelint.config.mjs` の詳細度の上限を、`"0,2,0"` から
  `"0,1,0"` と `ignoreSelectors`（状態と疑似要素）の組み合わせに変えた。
  これまでは `.c-a .c-b` のような組み合わせのセレクタも [0,2,0] として通っていた

**使っている側で直すこと**

- 設計書などで getup-css の 8 節・9 節を番号で参照していたら、9 節・10 節に直す
- 状態をクラス（`.is-open` など）で持っていたら、属性に置き換える
- 画面に入るまで隠すような指定を `scripting` で囲んでいなければ、囲む
- `stylelint.config.mjs` の `selector-max-specificity` を、ひな形と同じ設定に差し替える
- 差し替えて Stylelint が出したセレクタを、`:where()` に入れるなどして [0,1,0] に直す

## 2026-10-09

**変更**

- 6 節に「引数」を足した。親から値を受け取る変数は、`_` を付けずに block 名で始め
  （`--nav-inset`）、部品の側では `--_` 変数で受けて既定値を書く
- `--_` 変数の名前には、常に block 名を含めることにした（`--_min` → `--_grid-min`）。
  ひな形の `layout.css` の変数名も変えた

**使っている側で直すこと**

- block 名を含まない `--_` 変数の名前を、block 名を含む名前に直す
- ほかの部品の `--_` 変数を直接書き換えている箇所があれば、引数に置き換える
